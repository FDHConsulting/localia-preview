## FDH IA Consulting - Orchestration & Innovation
### Architecte Logiciel & IA (Auto-formation) > Projet LocalIA (2023-2025)
#### - Contexte :
- Architecture et développement d'un écosystème d'IA locale, éthique et open source basé sur des modèles locaux.
-  (LocalAI, Ollama), agentique multi-modale, et principes du **Triangle Gouvernail** (Démocratie, Distribution, Respect du Vivant)
#### - Objectifs :
- Concevoir une architecture **agentique modulaire** avec 8+ agents spécialisés communiquant via Bus API REST, intégrant **RAG** (Retrieval-Augmented Generation) et système de triple persistance
- Intégrer des **outils locaux** d'orchestration et d'automatisation (n8n workflows, ComfyUI génération multimodale) avec gestion de contexte
#### - Approche :
- **LLM locaux souverains** : LocalAI (Qwen 8B), Ollama pour inférence locale, Open-Webui comme hub RAG pour indexation et récupération contextuelle de documents
- **Architecture agentique** : Pattern agent-manager-workflow avec agents spécialisés (AgentQwen, AgentObsi, AgentDispia, AgentMongo) communiquant exclusivement via JSON et Bus Flask
- **Multimodalité** : Pipeline audio Whisper (transcription), Silero VAD (détection vocale), traitement image/vidéo, enrichissement contextuel temps réel
- **Intégration n8n et ComfyUI** : Orchestration workflows via n8n (webhooks, automation), génération visuelle via ComfyUI, bridges MCP pour accès filesystem
#### - Résultats :
- Écosystème IA éthique opérationnel avec **RAG natif**, orchestration n8n, génération multimodale ComfyUI et dashboard web centralisé
- Maîtrise approfondie des **LLM locaux**, architectures **agentiques**, **RAG**, **prompt engineering** et intégration d'outils no-code (n8n, ComfyUI)
